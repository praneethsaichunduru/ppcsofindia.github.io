# Permanent Pictorial Cancellations of India
A website (under development) which showcases the details of Permanent Pictorial Cancellations (Philately) across Indian states and Untion Territories.

The site is now built with React: see [react-site/README.md](react-site/README.md). The `.html` files in this folder are the previous version of the site, kept until the React version is signed off; only `react-site/` is published.
